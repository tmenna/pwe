Overview
What is the PWE Portal?
A private, password-protected web application for PWE staff and sponsors to manage child sponsorship records, documents, and communications — all in one place.

🎯 Purpose

Replace scattered spreadsheets and email chains with a structured, role-aware system that keeps every child's story safe, searchable, and up to date.

🔒 Access

Admin-issued accounts only — no public sign-up. Each user sees only what their role permits. Sponsors see only their assigned children.

🌍 Multi-Org Ready

Supports multiple partner organizations. Staff are scoped to their org; admins see everything.

Getting Started
Signing In
Access is granted by the system administrator. There is no public sign-up page.
1

Open the portal URL

Navigate to the published portal link in your web browser.

2

Enter your username & password

Use the credentials provided by your administrator. Contact your admin if you do not have an account.

3

Click Sign In

You will be directed to the dashboard (admins/case workers) or the Sponsor Portal (sponsors) based on your role.

Sessions are secure & server-stored

Feature · Administration
User Management & Roles
Admins control who can access the portal and what they can do. All four roles are managed from a single panel.
🛡️

Admin

Full access to every feature including user management, organization management, data export, and all child records across all organizations.

💼

Case Worker

Create and edit child profiles, upload documents, add timeline entries, and manage messages for their assigned organization.

👁️

Read Only

View child profiles, documents, and timeline entries — no ability to create, edit, or delete any records.

💗

Sponsor

Access their own assigned children only via the Sponsor Portal. Can send messages if admin has enabled commenting per child.

Feature · Sponsor Assignment
Assigning Children to Sponsors
Admins use a powerful searchable picker in the User Management panel to assign one or many children to a sponsor account.
1

Open User Management → Create or Edit a sponsor user

Navigate to Admin → User Management. Click Add User or the Edit icon on an existing sponsor.

2

Set role to Sponsor — child picker appears

An "Assigned Child Profiles" section appears with a live search input and a full scrollable list of all children.

3

Search and select individually — or use Select all shown

Type a name or ID to filter, then click a row to select it, or click "Select all N shown" to bulk-assign every matching child at once.

4

Control commenting per child (edit mode)

Use the global "Allow commenting — all selected" switch to enable messaging for all at once, or fine-tune per child with individual toggles. Mixed states are clearly indicated.

How to Use · Admin
Day-to-Day Admin Workflow
Typical tasks for an administrator managing the portal.
A

Create a child profile

Children → Add Child → fill in details → Save. Upload a profile photo from the child's profile page.

B

Create a sponsor account

Admin → User Management → Add User → set role to Sponsor → search and assign children → Save.

C

Create an organization

Admin → Organizations → Add Organization → enter name and description → Save. Assign children and users to this org.

D

Review pending messages

Dashboard alert shows unread messages. Click to open the queue, update statuses, or delete messages.

E

Export data

Children List → Export → select fields → choose CSV or XLSX → Download. Use for reports and external sharing.

F

Enable sponsor commenting

Edit a sponsor user → turn on "Allow commenting" per child. The sponsor will then see a message tab in their portal.

How to Use · Case Worker
Case Worker Workflow
Routine tasks for staff maintaining child records and tracking progress.
1

Update a child's status or details

Open the child's profile → click Edit → change status, age, location, or any field → Save. Status options: Active, Paused, Exited.

2

Upload a document

Child profile → Documents tab → Upload Document → choose a category (e.g. Progress Report) → add description → Upload. File is stored in cloud storage.

3

Add a timeline entry

Child profile → Timeline tab → Add Entry → select entry type, write title and description → Save. Entry appears at the top of the feed.

4

Log a sponsor message

Child profile → Messages tab → Send Message → enter sender name, role, and content → Send. Mark as Delivered or Read as the message is tracked.

How to Use · Sponsor
Sponsor Portal Walkthrough
Sponsors have a simpler, focused experience designed around their relationship with their child.
1

Log in with sponsor credentials

You are taken directly to the Sponsor Portal — a warm, dedicated view separate from staff pages.

2

View your child's profile

See the child's photo, name, age, location, and program information. If you sponsor multiple children, use the child-picker bar at the top to switch.

3

Browse documents and timeline

Switch between the Documents and Progress tabs to see uploaded files and milestone updates from the case team.

4

Send a message (if enabled)

If your admin has turned on commenting, a Messages tab appears. Write your message and click Send — staff will see it in their review queue.
